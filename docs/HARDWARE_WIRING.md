# HARDWARE_WIRING.md

## 硬件清单

- Raspberry Pi 4B + 独立5V USB-C电源
- USB 1080P自动对焦摄像头
- ADS1115 16位ADC
- 电容式土壤湿度传感器V2.0（AOUT）
- P451两线浮球水位开关
- YYMOS-1 MOSFET驱动
- 12V / RS385-635 / 3W 蠕动泵
- 独立12V 2A电源
- 10kΩ下拉电阻、硅胶管、储水桶、喷嘴固定件、接水盘

## 树莓派物理Pin

| 树莓派Pin | 功能 | 连接 |
|---:|---|---|
| 1 | 3.3V | ADS1115 VDD |
| 3 | GPIO2/SDA | ADS1115 SDA |
| 5 | GPIO3/SCL | ADS1115 SCL |
| 6 | GND | ADS1115 GND |
| 9 | GND | 土壤传感器 GND |
| 11 | GPIO17 | YYMOS-1 PWM |
| 13 | GPIO27 | P451线1 |
| 14 | GND | YYMOS-1 GND |
| 17 | 3.3V | 土壤传感器 VCC（确认支持3.3V后） |
| 20 | GND | P451线2 |

其他连接：土壤传感器 AOUT → ADS1115 A0；ADS1115 ADDR → GND（0x48）。GPIO17到GND必须有10kΩ外部下拉。

## 12V动力侧

```text
12V+ → YYMOS 电源输入+
12V- → YYMOS 电源输入-
YYMOS 输出PWM+ → 蠕动泵+
YYMOS 输出PWM- → 蠕动泵-
```

树莓派与12V控制侧必须按YYMOS要求共地，但任何12V正极不得进入树莓派针脚。YYMOS若无感性负载保护，增加续流二极管。

## 水路与防虹吸

```text
最高液位低于最终喷嘴至少5cm的储水桶
  → 进水管
  → 蠕动泵
  → 出水管
  → 固定在自由空气中的喷嘴
  → 水滴落入花盆
```

硬要求：喷嘴不插土、不浸水；水桶最高液位低于喷嘴；管路和喷嘴机械固定；水桶≤2L；接水盘容量≥水桶容量。普通单向阀只能防回流，不能作为正向防虹吸依据。

## 上电顺序

1. 树莓派和12V电源全部断电；
2. 逐线核对正负极和Pin；
3. 不接泵先验证GPIO默认LOW；
4. 接泵后只运行1秒诊断测试；
5. 完成水位、流量、滴漏和最低剂量标定后才允许自动守护。
