# GitHub 发布尝试（不含凭据）

- origin：`https://github.com/watsonbkeel/flower.git`；`git ls-remote origin HEAD`: exit 0、无返回 ref（当前空仓库）。
- `GIT_TERMINAL_PROMPT=0 git push origin HEAD:refs/heads/main`: exit 128，`could not read Username for 'https://github.com'`；本机没有可用HTTPS凭据。
- `ssh -T -o BatchMode=yes ... git@github.com`: exit 255，`Permission denied (publickey)`；未使用 aibot 凭据或在聊天/证据中记录密钥。
- 本地生成可复核完整历史的 Git bundle `.runtime/flower-source-final.bundle` 与原生小程序代码包 `.runtime/flower-miniapp-edu-36875df.zip`；包不包含生产凭据、运行时快照和用户未跟踪的启动文档。前者需要在最终文档提交后重新生成并通过 `git bundle verify`。
- 解除方式：用户在本机为该公开仓库配置写权限凭据，然后运行 `GIT_TERMINAL_PROMPT=0 git push origin HEAD:refs/heads/main`；推送成功后再用 `git ls-remote origin refs/heads/main` 核验 SHA。没有配置前不得声称已上传。
